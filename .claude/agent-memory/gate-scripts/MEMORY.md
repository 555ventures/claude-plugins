- [replay.js mode-flag dispatch](replay-js-mode-flag-dispatch.md) — one script, several mutually-exclusive `--mode` flags via a lookup object; root = process.cwd(), no --root flag, even for git-shelling modes
- [Parallel batch corpus landing](gate-scripts-parallel-batch-corpus-landing.md) — a cross-batch AC (e.g. needing a doctrine-authored corpus file) can go green from a sibling worker landing concurrently; check git status before calling `blocked`
- [Reviewer workflow-return schema](reviewer-workflow-return-schema.md) — raw wf.verdict is only "CLEAN"|"REVIEWER_FAILED" (ran-ok, not findings-count); don't confuse with verdict.js's derived FINDINGS/HARD_FINDINGS word
- [info/exclude is not per-worktree](info-exclude-not-per-worktree.md) — it resolves to the MAIN repo's .git/info/exclude, not the linked worktree's; use `rev-parse --git-dir` for any marker that must die with the worktree
- [gitStatus snapshot is stale vs live](gitstatus-snapshot-stale-vs-live.md) — conversation-start gitStatus can predate a file's real working-tree state; verify with live `git status`/`git show HEAD:`, and diff your edit against the pre-edit content you read, not blindly against HEAD
- [writeSync loop + configExists export](writesync-loop-and-config-exists-export.md) — fs.writeSync needs a while-loop for the 64KB-pipe fix; configExists/configPath/CONFIG_RELPATH are the only sanctioned routes now that naming spec.config.json under spec/scripts/ is banned
- [spec-sections.js tag anchoring](spec-sections-tag-anchoring.md) — oracle/env/pre-green tags parse only in declaration-slot or trailing position, each multi-tag-aware (a dropped sibling tag = fabricated hard finding); documentation-by-example must never read as a declaration
- [wave1 buffer-then-append for fail-closed precondition](wave1-buffer-then-append-for-fail-closed-precondition.md) — when one parallel leg can hard-abort with a "zero rows appended" guarantee, buffer all wave results and defer appendRow until after the abort check; write-as-you-go (review-legs.js's pattern) races the abort
- [Leg-exit origin tracking, not class-set membership](leg-exit-origin-tracking-not-class-set.md) — a finding class emitted from two different leg-loops must never be added to both legs' class-Sets (cross-contaminates both exits); track emission site via a Set of object references instead, never a field on the finding (specs/20260823/03 D9)
- [Queue overlay shared-lib scope](queue-overlay-shared-lib-scope.md) — a "virtual" read-only re-run of a write-path algorithm belongs in the shared lib too, even if the File Plan row only names doneness; undocumented domain concepts (superseded brief) need a real greppable signal, logged as a deviation, never silently skipped (specs/20260823/08)
- [console.log + process.exit pipe truncation](console-log-exit-pipe-truncation.md) — async pipe write + immediate process.exit(0) silently truncates at 64KiB, exit still 0; fix with a looped fs.writeSync helper, only at load-bearing large-print sites
- [Synthetic repro evidence must be corrected, not just fixed](synthetic-repro-evidence-must-be-corrected-not-just-fixed.md) — a correct fix with a synthetic-repro-sourced comment gets the comment rewritten to its real justification, plus a grep-able deviations-class entry at count N, never a doctrine edit at count 1
- [Render-gate implementation gotchas](render-gate-implementation-gotchas.md) — a bare `/word/` negative test regex can collide with a locked summary literal — anchor the probe (`/^word /m`), never rename the contract; a spec that pins both sides is a `blocked` return; spawnSync in a process that also runs an in-process http.Server starves that server for the child's whole lifetime — use async spawn()
- [Contracts table vs AC test conflict](contracts-table-vs-ac-test-conflict.md) — when a spec's quoted Contracts-table message can't satisfy its own Decision + AC test's blanket requirement, keep the quoted text verbatim as a prefix and append the missing phrase, then log a deviation — not `blocked`
- [Synthetic gate-command async-stdout truncation](synthetic-gate-command-async-stdout-truncates-before-runshell.md) — a repro fixture using `node -e "write();exit()"` for a large single-line write self-truncates at 64KiB before the code under test ever runs it; use `head -c N /dev/zero | tr` instead
- [Checkpoint outcome derived in shared arg-builder](checkpoint-outcome-derivation-in-shared-arg-builder.md) — a driver-derived flag threaded onto 3 shared verdict.js call sites belongs inside the one shared arg-builder (viaModelArgs-style), not fanned out to each call site
- [collision-closure tier is additive, not exclusive](collision-closure-tier-additive-not-exclusive.md) — a runnable-target hit still runs isLikely unconditionally (may print under both executes: and likely:); only the non-runnable mentions: catch-all is suppressed for runnable targets — check ordering/overlap clauses before reading a Decision's binary branch as mutually exclusive
- [New driver check vs shared fixture collision](new-driver-check-vs-shared-fixture-collision.md) — an unconditional new check reddens every pre-D-spec shared fixture, even one whose own header comment claims exemption; trust the dedicated AC fixture passing over a stale sibling comment, log each collision, never narrow the check
