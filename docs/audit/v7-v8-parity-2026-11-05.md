# v7-to-v8 parity audit

Date: 2026-11-05. Compares the `spec-v7-final` tag with main after spec 20261105/13 merged. Read-only: no code changed.

## How to read this

- **Lost by accident** means no design doc, ADR or spec line decided the cut. It does not mean the behaviour must return: a harmless loss still lands here.
- **Cut on purpose** cites the line that decided it.
- **Decided by spec 14** rows are prototype behaviours that the locked spec 20261105/14 replaces or rules out. The readers wrote them as lost, because spec 14 was still a draft when they read it.
- Rows are not de-duplicated across areas: one behaviour can appear twice (the `/spec:run` status refusal, for one).

## Limits

- Most rows come from reading code. Rows tagged `[ran]` or `(ran)` were executed on throwaway fixtures. The plan/run/fix and doctor/init/enforce readers had their fixture runs denied, so none of their rows were executed; the side-by-side runs below cover some doctor and init ground.
- Line numbers for `run.js`, `plan.js`, `lib/state.js` and `docs/v8/architecture.md` may have moved: a concurrent session edited them during the audit.
- 11 doctor/init/enforce rows tagged `[E]` depend on how `docs/v8/architecture.md` line 216 is read. Read as a blanket cut of enforce, they move to cut on purpose.
- `docs/v8/interface-contract.md` says v8 "must keep what is listed here", yet still lists behaviours other docs cut. Those rows carry a `[conflict]` tag or a note in their verdict.
