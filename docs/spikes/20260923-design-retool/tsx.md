## Setup pain
- `shadcn init -t vite -b radix -n app -y -s` stops at an interactive monorepo prompt even with `-y`. It also needs `--no-monorepo` and a preset (`-p nova`); without them it stops at a preset picker. The command that worked: `npx shadcn@latest init -t vite -b radix -p nova -n app -y -s --no-monorepo -c <tsx>`. It scaffolds into `tsx/app/`.
- Nova is already neutral gray, so no theme work was needed.
- One TS error: an optional field on a union-inferred record needed `?.` narrowing.
- `playwright install chromium` deleted older Chromium builds from the shared `~/Library/Caches/ms-playwright`, which is outside the sandbox.

## What I could not express
- Kodai's mandate line isn't in the records, so the box shows a placeholder.
- The records have no state for the moment mid-session. I show fact F-0398 as the current card and use the ratio of facts already read back for progress.
- Three pieces of copy are written by hand, not taken from the records: "Voice or text: Your choice", the step names, and the button labels.
- Tap-to-remove topics are fake (a "×" inside a Badge). No interaction state.

## Judgment
Very ergonomic for an agent: shadcn + Tailwind are well known and typechecked. It costs about 1.2k tokens per screen, mostly `className` strings, and the scaffold CLI's prompts are the only real snag.
