## Acceptance Criteria

- **AC-20261105-17-1**: WHEN `init.js --set testCommand='exit 1'` runs THE SYSTEM SHALL print `config written — gate not verified` and a `testCommand exited 1` warn, exit 0, and print no `gate verified`; WHEN the command exits 0 THE SYSTEM SHALL print `✅ initialized — config written, gate verified`.
- **AC-20261105-17-2**: WHEN package.json holds `type-check` and `lint:ci`, or a Makefile holds `lint:` and `typecheck:` targets, or a bun lockfile sits beside `lint` THE SYSTEM SHALL chain `npm run lint:ci && npm run type-check && …`, `make lint && make typecheck && …` and `bun run lint && …` respectively; WHEN only `.eslintrc`, `tsconfig.json`, `.golangci.yml` or `Cargo.toml` is present THE SYSTEM SHALL add no check.
- **AC-20261105-17-3**: WHEN no test command is detected, `lint` exists and `--set testCommand=make test` answers THE SYSTEM SHALL write `npm run lint && make test`; WHEN init re-runs on a config whose `testCommand` lacks a detected check THE SYSTEM SHALL add it, and a further run SHALL change nothing; WHEN `testCommand` is `pnpm turbo run typecheck lint build test`, or `bash scripts/gate.sh` whose file runs the check, or `npm run check` whose script runs it, THE SYSTEM SHALL leave it byte-identical.
- **AC-20261105-17-4**: WHEN `trimConfig` reads `gateCommand: "bash scripts/spec-gate.sh {scopeDirs}"`, `"a && node --test {testDirs}"` and `"g {testFiles}"` THE SYSTEM SHALL give `testCommand` `bash scripts/spec-gate.sh`, `a && node --test` and `g`, with no `typecheckCommand` prefix; WHEN it reads `FOO=${BAR} a && b` THE SYSTEM SHALL keep it whole; WHEN the gate is only a placeholder THE SYSTEM SHALL fall back to `testCommand`, with `typecheckCommand` prefixed.
- **AC-20261105-17-5**: WHEN `--apply` runs on a v7 host holding `.claude/rules/enforcement.json` and `enforcementManifest` THE SYSTEM SHALL CONTINUE TO move the file to `docs/archive/v7/rules/enforcement.json` and drop the key; `docs/v8/host-footprint.md` SHALL say ARCHIVE on that file's row, and `doctor.js` SHALL hold no `enforcementManifest`.
- **AC-20261105-17-6**: WHEN `--apply` runs on a config holding `laneFiles`, `gateConcurrency`, `askPaths` and `doctorProbeMs` THE SYSTEM SHALL keep all four; WHEN it holds `mergeStrategy: "derived"` or `"rebase-ff"` THE SYSTEM SHALL drop the key, and SHALL CONTINUE TO keep `squash`.
- **AC-20261105-17-7**: WHEN a config holds `capabilities.testCountPattern` THE SYSTEM SHALL write it to `release.testCountPattern`, verbatim for `none`, keeping every other `release` key; WHEN it holds none THE SYSTEM SHALL add no `release` key; WHEN `--apply` runs twice THE SYSTEM SHALL print `✅ nothing to migrate` the second time.
- **AC-20261105-17-8**: WHEN status counts N hygiene anomalies on a host THE SYSTEM SHALL have doctor report the same N as `roadmap: [` findings and exit 1, and print each decide anomaly as an info line that adds no finding.
- **AC-20261105-17-9**: WHEN a `.gitignore` entry is missing THE SYSTEM SHALL end the finding with `run /spec:migrate` on a config with `generatedBy` and `run /spec:init` otherwise, and `IGNORE` SHALL CONTINUE TO hold its four entries.
